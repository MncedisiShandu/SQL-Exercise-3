# SQL CASE Statements Exercise

## Overview

This project focuses on SQL `CASE` statements for classifying data into meaningful categories based on specified conditions. It contains 10 practice questions using different tables and business scenarios.

## Topics Covered

* SQL `CASE` expressions
* Conditional logic using `WHEN`, `THEN`, `ELSE`, and `END`
* Comparison operators and logical conditions
* Data classification and categorisation
* Column aliases using `AS`
* Predicting query output

## Exercises

The exercises cover product pricing, order values, employee seniority, student grades, delivery performance, ticket priorities, attendance percentages, stock levels, class sizes, and discount eligibility.

## Learning Objectives

To develop practical SQL skills by writing queries, applying conditional logic, and understanding how data can be classified based on specific rules.

## Tools

* SQL
* Pen-and-paper query writing and output analysis
